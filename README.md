# MCF Movie Recommender

Программная модель многокритериальной рекомендательной системы для фильмов.

Проект реализует рекомендательную модель, которая формирует прогноз общей оценки фильма и оценки по четырём критериям:
- Сюжет;
- Визуальная составляющая;
- Актёрская игра;
- Атмосфера.

Основная модель `MCF_Full` использует эмбеддинги пользователей и фильмов, метаданные объектов, критериальные прогнозы и персональные веса критериев.

## Возможности

- Рекомендации фильмов для пользователя из базы;
- Рекомендации для нового пользователя по введённым оценкам;
- Прогноз общей оценки `overall`;
- Прогнозы по критериям `plot`, `visual`, `acting`, `emotion`;
- Отображение профиля значимости критериев;
- Демонстрационный интерфейс на Streamlit.

- Python 3.12;
- PyTorch;

## Запуск проекта

### 1. Создание виртуального окружения

```bash
python -m venv venv
```

### 2. Активация виртуального окружения

Для Windows:

```bash
venv\Scripts\activate
```

Для Linux / macOS:

```bash
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Запуск интерфейса

```bash
streamlit run app.py
```

После запуска Streamlit откроет веб-интерфейс в браузере.

## Режимы работы интерфейса

### Существующий пользователь

Пользователь выбирается из базы по `user_id`.
Система отображает историю оценённых фильмов и формирует список рекомендаций, исключая уже просмотренные фильмы.

### Новый пользователь

Пользователь выбирает несколько фильмов и выставляет оценки по четырём критериям.
После этого система ищет похожий профиль среди пользователей обучающей выборки и формирует рекомендации.

Для каждой рекомендации отображаются:

- Название фильма;
- Жанры;
- Прогноз общей оценки;
- Прогнозы по четырём критериям;
- Профиль значимости критериев.

## Модели

В проекте реализованы четыре архитектуры:

- `BaselineNCF` – базовая однокритериальная нейронная модель;
- `MCF_NoMeta` – многокритериальная модель без метаданных;
- `MCF_FixedWeights` – многокритериальная модель с фиксированными весами критериев;
- `MCF_Full` – полная многокритериальная модель с персональными весами критериев.
